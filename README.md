# NITPY Alumni
## ~ ojas

Features:
1. Login / Signup
2. Admin Panel
3. Email Sending automation
4. User verification
5. Alumni Card using Pillow (Automated)
6. Chat Features
7. Features such as booking rooms, transcript, book donation

### Made with Django

# Setup

Use ```pip install -r requirements.txt```
Then, 

`python manage.py makemigrations`

`python manage.py migrate`

`python manage.py runserver `
